## Использование модуля

### 1. Установка и настройка

1. Поместите модуль в папку addons Odoo
2. Обновите список модулей: `Настройки -> Модули -> Обновить список модулей`
3. Установите модуль `geo_field_widget_fias`
4. Получите API ключ FIAS и добавьте в системные параметры:
   - Ключ можно взять из лбого запроса в браузере https://fias-public-service.nalog.ru
     или пройдя регистрацию на официальном сайте.
   - Перейдите в `Настройки -> Технические -> Параметры -> Системные параметры`
   - Создайте параметр с ключом `geo_field_widget_fias.api_key` и значением вашего API ключа

### 2. Подключение к полю модели

```xml
<!-- В XML представлении добавьте атрибут с виджетом -->
<field name="address_text" widget="geo_field_widget_fias"/>
```

### 3. Создание новой модели с адресом

```python
class DeliveryPoint(models.Model):
    _name = 'delivery.point'
    _description = 'Точка доставки'

    address_text = fields.Char('Название', required=True)
```
